# Safe QR

Know what a QR code does before you act on it.

Safe QR is a native iOS app (Czech and English) and the website [safeqr.cz](https://safeqr.cz). It decodes any QR code, explains it in plain language, gives it a 0–100 risk score and asks for an explicit decision before anything is opened, paid or sent.

Built at [The FinTechers Hackathon 2026](https://thefintechers.notion.site/hackers-guide_-The-FinTechers-Hackathon-2026-3f41e819981381cf9981d4d0e6f62eba) (Prague, 19–20 October 2026), Track 7 · Open.
